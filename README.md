# Apuntes de Sistemas Informáticos (DAW)

Apuntes del módulo profesional Sistemas Informáticos, CFGS Desarrollo de Aplicaciones Web (Comunitat Valenciana), construidos con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Desarrollo local

```bash
pip install -r requirements.txt
mkdocs serve
```

Abre http://127.0.0.1:8000

## Despliegue

El sitio se despliega automáticamente en GitHub Pages mediante GitHub Actions (`.github/workflows/deploy.yml`) al hacer push a `main`.

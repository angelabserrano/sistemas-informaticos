# Plantilla: ficha técnica de un equipo

Utiliza esta plantilla para completar la **Actividad 1.1**. Rellena cada campo con los datos identificados en el equipo desmontado (o en el catálogo de imágenes proporcionado por el profesorado).

| Elemento | Datos a identificar |
| --- | --- |
| Chasis | Formato (torre, minitorre, slim, sobremesa...) |
| Fuente de alimentación | Formato y potencia (si es visible) |
| Sistema de refrigeración | Tipo (aire, líquida) y elementos (disipador, ventiladores...) |
| Placa base | Formato (ATX, Micro-ATX, Mini-ITX...) |
| Procesador | Modelo (si es visible) y tipo de zócalo |
| Módulos de memoria RAM | Formato (DIMM/SO-DIMM), cantidad de módulos y capacidad |
| Unidades de almacenamiento | Tipo (HDD/SSD) e interfaz (SATA, M.2/NVMe...) |
| Tarjetas de expansión | Tipo (gráfica, red, sonido...) y tipo de ranura, si el equipo dispone de alguna |
| Periférico 1 | Tipo y conector |
| Periférico 2 | Tipo y conector |
| Periférico 3 | Tipo y conector |

!!! tip "Cómo usarla"
    Copia esta tabla en tu documento de entrega y sustituye cada celda de la derecha por los datos reales del equipo. Adjunta también las fotografías/etiquetas de cada elemento identificado.

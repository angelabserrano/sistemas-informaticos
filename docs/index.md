# Sistemas Informáticos

## Resultados de aprendizaje

| RA | Descripción | Unidad(es) |
| --- | --- | --- |
| RA1 | Evalúa sistemas informáticos, identificando sus componentes y características. | UT1 |
| RA2 | Instala sistemas operativos planificando el proceso e interpretando documentación técnica. | UT2 |
| RA3 | Gestiona la información del sistema identificando estructuras de almacenamiento y aplicando medidas para asegurar la integridad de los datos. | UT3 |
| RA4 | Gestiona sistemas operativos utilizando comandos y herramientas gráficas evaluando las necesidades del sistema. | UT3 |
| RA5 | Interconecta sistemas en red configurando dispositivos y protocolos. | UT4 |
| RA6 | Opera sistemas en red gestionando sus recursos e identificando restricciones de seguridad. | UT4 |
| RA7 | Elabora documentación valorando y utilizando aplicaciones informáticas de propósito general. | UT1, UT2, UT4 (transversal) |

## Distribución horaria

El módulo se organiza en 4 unidades de trabajo, con un total de **140 horas en el centro educativo** y **26 horas de formación en la empresa**, a razón de **5 horas semanales**.

| Unidad de trabajo | Horas |
| --- | --- |
| UT1. Arquitectura y componentes de los sistemas informáticos | 25 |
| UT2. Sistemas operativos: Instalación y primeros pasos | 45 |
| UT3. Sistemas operativos: Configuración y administración | 35 |
| UT4. Redes y sistemas operativos en red | 35 |
| **Total en el centro** | **140** |
| Formación en la empresa | 26 |
